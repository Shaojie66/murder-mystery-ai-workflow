# Web 版的本地单用户边界（R12）

- 更新日期：2026-10-26
- 状态：当前实现的事实记录；**不是**公网或多用户发布方案，也没有实施任何 SaaS 能力
- 对应：[实施方案](./reliability-mvp-plan.md) R12、[任务清单](../TODOS.md)

## 当前可以怎么用

Web 版只适合**本机、单个使用者**：后端监听 `127.0.0.1`，作品和设置都在本机的 `~/.murder-wizard/` 下。

## 已核实的事实（截至 2026-10-26，读自代码）

| 事项 | 现状 | 对公网或多用户意味着什么 |
| --- | --- | --- |
| 令牌 | `POST /api/user/auth/token` 对任意 `user_id` 直接签发 JWT，不要求任何凭据 | 令牌不代表真实登录，任何人都能给自己签一个 |
| 作品目录 | 所有作品都在同一个 `~/.murder-wizard/projects/` 下，路径只由作品名决定，没有按用户隔离 | 同一服务上的任意已持令牌者能读写任何作品 |
| 设置 | `/api/settings` 路由没有鉴权依赖；设置文件 `~/.murder-wizard/settings.json` 可能含明文 API key | 公网暴露等于暴露密钥 |
| 留资与统计 | 邮箱和事件追加写入 `~/.murder-wizard/landing/{subscriptions,events}.jsonl`（目录 0700、文件 0600，邮箱是个人信息），启动后首次使用时回放；工具不自动删除、不改写，要清理请手动删文件；损坏行跳过并在响应里计数；写盘失败返回 503，不会谎称已记录。`/api/landing/subscriptions` 与 `/api/analytics/events` 仍没有管理员保护 | 只适合本地单进程（多进程同时写没有保证）；仍然只代表兴趣，不能作为留存或付费证据，也不应公开 |
| 任务并发 | 同一作品同一时刻只允许一个写入任务（进程内登记）；没有跨进程的锁 | 多进程或多实例部署下不成立 |
| 费用 | 没有按用户的预算上限；调用云端模型的费用由配置的 key 所有者承担 | 公网部署前需要成本控制 |

## 公网或多用户发布之前至少要先做的评审（尚未实施）

1. 真实身份（登录、令牌签发要凭据），不再以"已有令牌"代替登录。
2. 作品归属与授权：每个作品绑定所有者，所有读写与任务接口按所有者校验。
3. 设置隔离与密钥保管：API key 不明文落盘，设置接口必须鉴权。
4. 数据持久化与备份：作品的版本与备份方案；留资和统计目前只是本地 JSONL，多进程与保留策略仍未设计。
5. 成本控制：按用户或按作品的预算与速率限制。
6. 任务锁与取消：跨进程的作品写锁；可真正中断的取消语义。

以上每一项都属于需要另行设计和批准的工作，本轮不包含。在它们完成之前，请不要把这个 Web 服务暴露到公网，也不要用现有的留资和统计数据判断付费意愿。
