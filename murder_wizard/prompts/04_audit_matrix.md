## 任务
对照信息矩阵，逐角色、逐事件检查 a 本、b 本的描述是否与矩阵一致。

### 维度1：知识边界
- 矩阵中该角色该事件的状态为“否”，但 a 本/b 本提及了该信息 → P0
- 矩阵标注“疑”的信息被当作“知”使用 → P1

### 维度2：时间线
- 同一事件内的时间顺序矛盾 → P1
- 跨事件顺序颠倒（先知道后发生的事）→ P0

### 维度3：秘密泄露
- 角色 A 的秘密在角色 B 的 a 本中被提及 → P0
- 角色 A 的秘密被角色 B 通过 b 本搜证获得，且属于预期内 → P1

### 维度4：视角真实性
- 角色行为与 background.md 的设定矛盾 → P1
- 角色心理描写与已知信息不匹配 → P2

## 严重度
P0 = 玩家会被“穿帮”、无法推理或走入死路，必须修；P1 = 应修；P2 = 可选。
